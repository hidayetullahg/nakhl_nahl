# NAKHL&NAHL Administrator Guide

## 1. System Administration & RBAC
NAKHL&NAHL includes comprehensive enterprise administration controls:
- **Tenant Management:** Provisioning organizations, branches, and custom domains.
- **Role-Based Access Control (RBAC):** Granular permission assignments (Superadmin, Tenant Admin, Accountant, Warehouse Manager, Sales Representative, Cashier).
- **Security Audit Logging:** All user authentication events, permission alterations, and financial exports are logged to tamper-evident audit tables.

## 2. Help System Administration
Administrators can access `Ayarlar` → `Yardım Yönetimi` (`/help-admin`) to:
- Dynamically create and modify procedural help articles.
- Add or reorder step-by-step guidance.
- Configure contextual form tooltips.
- Assign audience roles (e.g. restrict accounting guides to accountants).
- Manage Turkish, English, and Arabic translations.
- Review user onboarding completion metrics and identify screens with high drop-off rates.
